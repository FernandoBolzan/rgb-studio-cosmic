# Contribuindo / Contributing

[English](#english)

## Português

- Abra uma issue antes de mudanças grandes e descreva o ambiente, a versão do OpenRGB e os dispositivos envolvidos.
- Não publique `settings.json`, cenas pessoais, logs com informações privadas nem dados de identificação do hardware.
- Mantenha a interface e a documentação em português e inglês.
- Antes de enviar uma alteração, confira a sintaxe com `python3 -m py_compile rgb_panel.py` e descreva o que foi verificado.
- Mudanças que escrevem nos LEDs devem ser opt-in e deixar claro qual dispositivo ou zona será alterado.

## English

- Open an issue before large changes and include the desktop environment, OpenRGB version, and affected devices.
- Do not publish `settings.json`, personal scenes, logs containing private information, or hardware identifiers.
- Keep the interface and documentation available in Portuguese and English.
- Before submitting a change, check syntax with `python3 -m py_compile rgb_panel.py` and state what you verified.
- Changes that write to LEDs must be opt-in and clearly identify the target device or zone.
